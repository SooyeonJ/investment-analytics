## 1. 투자철학

> 매크로(거시경제) + 모멘텀(주도주 중심) + 퀀트(백테스트) 기반 액티브 투자 전략

- 위험자산 : 안전자산 = 7 : 3 운용
- 회전율 적극 활용 예정
- 주도 섹터 중심 투자 예정
- 가격 조정 시 분할 매수 전략 활용
- 국내·해외 ETF 통합 운용 예정

- 최종 투자철학 : **"시장의 방향은 매크로가 만들고, 수익의 크기는 모멘텀이 결정하며, 생존은 퀀트가 완성한다."**
