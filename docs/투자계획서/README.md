## 1. 투자철학

### 투자 방향

> 매크로(거시경제) + 모멘텀(주도주 중심) + 퀀트(백테스트) 기반 액티브 투자 전략

- 위험자산 : 안전자산 = 7 : 3 운용
- 회전율 적극 활용 예정
- 주도 섹터 중심 투자 예정
- 가격 조정 시 분할 매수 전략 활용
- 국내·해외 ETF 통합 운용 예정

---

### 투자철학 초안

- 조원희
  - 불확실성이 증폭되는 오늘날, 메크로를 통해 단일적인 현상에 집중하는 것이 아닌 하나의 유기적인 흐름 속에서 현상을 해석한다. 그러한 흐름 속에서 기저의 모멘텀을 발견하고, 데이터 기반 분석을 통해 모멘텀을 검증한다.
  - 각자도생의 시대로 접어드는 거시경제의 거대한 움직임 속에서 본질적인 변화의 모멘텀을 발견하고, 데이터 기반 분석을 통해 검증하다.
  - 불확실성의 시대, 메크로를 읽고 기저의 본질적인 흐름을 파악하다. 그러한 변화 속에서 모멘텀을 찾아내고, 모멘텀을 퀀트로 검증한다. 

- 정수연
  - "매크로로 시장을 읽고, 모멘텀으로 주도주를 선점하며, 퀀트로 수익을 검증하는 액티브 투자"
  - 거시경제의 흐름 위에서, 주도주 모멘텀을 포착하고, 퀀트로 승률을 극대화한다
  - 매크로로 방향을 설정하고, 모멘텀으로 주도주에 집중하며, 퀀트로 검증된 수익을 추구한다

- 함동관
  - 거시경제 흐름이 만드는 방향성 위에 모멘텀의 지속성을 포착하고, 이를 퀀트 기반 데이터 분석으로 검증하여 확률적으로 우위 있는 투자만 집행한다. 
  - 시장의 방향은 매크로로 판단하고, 종목 선택은 모멘텀과 퀀트로 정교화한다. 
  - 시장의 방향은 매크로가 만들고, 수익의 크기는 모멘텀이 결정하며, 생존은 퀀트가 완성한다.
