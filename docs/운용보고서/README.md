## 🧾 평가 항목 ↔ 분석 산출물

| 평가 항목         | 작성 방향                                        | 분석 산출물      |
| ------------- | -------------------------------------------- | ----------- |
| 수익률 자체 평가     | 월간 포트폴리오 수익률, 성과 기여 자산군, 부진 자산군, 시장 대비 성과 분석 | 자산군별 기여도 차트 |
| 포트폴리오 변경 사유   | 매수·매도 ETF, 비중 조정 배경, 시장 변화 대응, 리스크 관리 사유 정리  | 리밸런싱 전후 시뮬레이션 |
| 익월 전망 및 투자 전략 | 국내외 증시, 금리, 환율, 원자재 등 주요 변수 전망과 익월 운용 계획 작성  | 모멘텀 스코어 랭킹  |

세 산출물은 이야기 순서이기도 하다: **"이번 달 뭐가 잘·못 됐나(①) → 그래서 뭘 어떻게 바꿨나(②) → 다음 달엔 뭘 할 건가(③)"**. 각 섹션은 앞 섹션의 결과를 근거로 이어써야 한다.

## 1. 자산군별 기여도 차트 — `01_기여도-차트.py`

이번 달 수익(또는 손실)이 **어느 자산군에서 왔는지** 분해한다.

- **데이터 출처** : 엑셀만 사용. `팀 전체`(포트폴리오 총액)와 자산군별 행의 일별 평가금액을 읽어 (월초 비중) × (수익률) = 기여도(%p) 계산
- **산출물** : 가로 바차트 — 자산군별 기여도 랭킹
- **재사용** : `--file`, `--month`만 바꿔 매달 그대로 재실행 (코드 수정 불필요)

**리포트 연결** : "포트폴리오 수익률 +2.90% 중 해외주식 지수가 +3.97%p로 견인, 국내주식 지수가 -1.56%p로 발목" ☞ 이 문장이 이 차트에서 그대로 명시

## 2. 리밸런싱 전후 시뮬레이션 — `02_리밸런싱-시뮬레이션_YYYY-MM.py`

"그 리밸런싱, 실제로 효과가 있었나?"를 **가격으로 증명**한다.

- **데이터 출처** : 엑셀 + pykrx. 엑셀에서 매도·매수 **시점**(보유구간)만 자동 감지하고, 실제 수익률은 AS-IS·TO-BE 양쪽 다 **pykrx로 조회한 KRX 실제 종가**로 계산한다 (엑셀 평가금액을 그대로 쓰면 분할매수 때문에 왜곡됨 — +9480%p 오류 발생 이력 있음)
- **사람이 채워야 하는 값** : `REBAL_EVENTS` — 어떤 ETF를 팔아 어떤 ETF를 샀는지 짝짓기는 자동 추론 불가, 매달 수동 입력
- **산출물** : 가로 바차트 — AS-IS 수익률 vs TO-BE 수익률, 효과(%p) 표기
- **사전 조건** : `KRX_ID`/`KRX_PW` 환경변수 필요 (data.krx.co.kr 회원가입)
- **재사용** : 매달 `REBAL_EVENTS`가 바뀌므로 파일 자체를 월별로 복사 (`_2026-06.py` → `_2026-07.py`)

**리포트 연결** : "국고채30년스트립을 팔고 단기특수은행채로 갈아탄 판단이 감이 아니라 +7.74%p 실증됨" ☞ 정성적 서술에 정량적 근거를 붙이는 섹션.

## 3. 모멘텀 스코어 랭킹 — `03_모멘텀-스코어_YYYY-MM.py`

지금 들고 있는 ETF들의 **추세 순위**를 매겨 다음 달 교체 후보를 가려낸다.

- **데이터 출처** : pykrx로 가격 조회. 대상 종목 리스트(`ETF_MAP`)는 엑셀의 최신 보유내역을 보고 사람이 직접 채워넣음 (자동 반영 아님)
- **계산** : 모멘텀 스코어 = 1M + 3M + 6M 수익률 합산 (12M은 상장 초기 ETF의 이상급등 구간이 스코어를 왜곡해 제외)
- **산출물** : 가로 바차트 — ETF별 모멘텀 스코어 순위
- **사전 조건** : `KRX_ID`/`KRX_PW` 환경변수 필요
- **재사용** : `ETF_MAP`이 바뀌므로 파일 자체를 월별로 복사

**리포트 연결** : "모멘텀 최하위 TIGER 국고채30년스트립은 익월 교체 1순위, KODEX AI반도체·KODEX 200은 유지" ☞ 과거 1~6개월 추세를 근거로 순위를 매겨, 다음 달 운용계획(유지/교체)을 세우는 데 참고
