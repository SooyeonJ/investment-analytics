### 1. 자산군별 기여도 차트

DB GAPS 포트폴리오 일별 평가금액 데이터를 활용하여 월간 수익률을 자산군 단위로 분해합니다.

* 활용 데이터 : 팀 전체 평가금액, 자산군별 평가금액, ETF별 일별 평가금액
* 전처리 방식 : ETF 티커와 자산군 분류 매핑 ⇒ 월초·월말 기준 데이터 정리
* 분석 방식 : `pandas groupby()` 활용 ⇒ 자산군별 평가금액, 비중, 수익률 집계
* 계산 지표 : 자산군별 수익률, 자산군별 비중, 포트폴리오 수익률 기여도
* 차트 구성 : 가로 바차트 / X축 - 수익률 기여도 / Y축 - 자산군
* 활용 목적 : 월간 포트폴리오 성과에 기여한 자산군과 부진 자산군 확인

---

### 2. 리밸런싱 전후 시뮬레이션

ETF별 일별 평가금액 변화를 바탕으로 리밸런싱 전후의 성과 차이를 비교합니다.

* 활용 데이터 : ETF별 일별 평가금액, ETF 티커, 리밸런싱 발생일, 주요 변경 사유
* 전처리 방식 : 평가금액 변화 구간 확인 ⇒ 매수·매도 및 비중 조정 여부 파악
* 분석 방식 : 월초 포트폴리오 유지 시나리오와 실제 리밸런싱 반영 시나리오 비교
* 계산 지표 : 실제 포트폴리오 누적수익률, 가상 보유 누적수익률, 리밸런싱 효과
* 기술 방식 : `pandas`로 일별 평가금액 변화 추적 ⇒ 필요 시 `pykrx` 가격 데이터로 보완
* 차트 구성 : 라인차트 / X축 - 거래일 / Y축 - 누적수익률
* 활용 목적 : 포트폴리오 변경 사유를 정성적 판단이 아닌 정량적 근거로 설명

---

### 3. 모멘텀 스코어 랭킹

ETF별 과거 수익률을 기반으로 모멘텀 점수를 산출하여 익월 운용 판단에 활용합니다.

* 활용 데이터 : ETF 티커, ETF별 일별 종가, 기준일, 현재 편입 여부
* 데이터 수집 : `pykrx` 활용 ⇒ ETF별 과거 가격 데이터 수집
* 전처리 방식 : 기준일 기준 1개월, 3개월, 6개월, 12개월 전 가격 추출
* 분석 방식 : 기간별 수익률 계산 ⇒ 합산 점수 기준 ETF 순위 산출
* 계산 지표 : 1M 수익률, 3M 수익률, 6M 수익률, 12M 수익률, 모멘텀 스코어
* 계산 방식 : `모멘텀 스코어 = 1M 수익률 + 3M 수익률 + 6M 수익률 + 12M 수익률`
* 정렬 방식 : `pandas sort_values()` 활용 ⇒ 모멘텀 상위 ETF 도출
* 차트 구성 : 가로 바차트 / X축 - 모멘텀 스코어 / Y축 - ETF명
* 활용 목적 : ETF 유지, 교체, 신규 편입 판단을 위한 데이터 기반 근거 확보
